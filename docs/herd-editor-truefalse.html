The true/false control

Every boolean in the Herd Editor renders through one treatment. Option B shipped; this page is kept as the record of what was compared and why. Real tokens, real metrics — 13px base, 6px radius, #dcdcde hairlines.

Three further failures. Green is overloaded — the style guide reserves it for selection and the primary action, so a green filled chip reads as "press me". The chip hugs its label, so in a column of full-width fields sharing a left edge it belongs to a different UI. And the label bolds when checked, so the text reflows as you toggle.

Option A — checkbox rowconsidered

A native checkbox, visible in both states. Off is unmistakably an empty box; on is a green box with a tick. Nothing about either state suggests a button. The box sits on the same left edge as every field label, so the control belongs to the form. Label weight never changes.

The grid is auto-fill minmax(210px, 1fr), so a set of eleven still packs into three columns and stays scannable — denser than the pills were, because a row is 24px against the pill's 40px. Hide block keeps its grey exception: it fills --herd-ink-3 rather than green, because a hidden block is a state, not an enabled feature. Try tabbing through — the focus ring lands on the box.

Option B — small switchshipped

Reads as a state from further away, and the on/off distinction is the strongest of the three. Costs more vertical room and more pixels of colour per row, and switches usually imply an action takes effect immediately — which is untrue here, since nothing saves until Update.
