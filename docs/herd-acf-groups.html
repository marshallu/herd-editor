Why it opens itself
An incomplete group forces itself open and stays open. A required field that hides behind a closed row is the one real failure mode of this pattern, so it isn't allowed to happen.
Summary line
First two filled text-ish fields, joined by a middot, truncated at the row. Never image filenames or IDs when a human-readable field exists.

Depth cap
Two levels of collapsible, maximum. A group inside a group renders as option B's left rail instead — a third fold is a place for content to get lost.
4

Rules

What the component decides on its own, so the same group behaves the same way in every block.

RuleBehavior
Default stateCollapsed when every required field is filled. Open when the group is incomplete, or when it's the only group on the screen.
Summary lineFirst two non-empty text, textarea, select, or link-label fields, joined by ·. Falls back to the empty-state invitation. Never shows a filename, post ID, or raw URL when a labeled field exists.
Badgen of n set when complete or partial · Empty when nothing is filled · Needs [field] when a required field is missing. Counts only fields the editor can see — conditionally hidden fields don't count against the total.
Forced openAn incomplete group opens on load and can't be collapsed until the required field is filled. Save with one still open scrolls to it.
Gated groupsSwitch lives in the row, left of the title. Off collapses and disables the disclosure, keeps stored values, and suppresses validation.
DepthTwo collapsible levels maximum. Deeper nesting falls back to a left rail.
KeyboardRow is a real <button> with aria-expanded and aria-controls. The switch is a separate tab stop that doesn't trigger the disclosure.

One thing the style guide doesn't cover

The guide reserves #b32d2e for destructive hover only, but this component needs a validation color — the "Needs YouTube ID" badge and the errored input above are both using it. That's a conflict, not an omission, so it needs a decision rather than a quiet override.

My recommendation: name #b32d2e as the error color outright, with #fcf0f1 tint and #f0b8b8 line, and keep destructive hover as a second use of the same value. Two meanings for one red is fine when both mean "this needs your attention."
