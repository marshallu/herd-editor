What changed

  • The poster does the work the icon was doing. A 160px frame from the thumbnail field identifies the video at a glance, and clicking it plays the file in place — editors can confirm they attached the right cut without leaving the screen.
  • 190px of empty grey becomes a 92px row. Video, backup video, and thumbnail now read as three variations on one component instead of three unrelated widgets.
  • Metadata that answers real questions. Format, dimensions, size, and upload date, on one line with dot separators. Duration sits on the poster where video players put it.
  • Edit and Remove are labelled buttons. The bare × next to the thumbnail is replaced everywhere by text, so nothing destructive is a guess.
  • The empty state asks for something. Accepted formats, size cap, and a plain sentence explaining what a backup video is for — the current "Choose a file" says none of it.
  • States are designed, not left to chance. Uploading, missing-poster, and rejected-file all reuse the same row, so nothing jumps around as the field changes.

What shipped

  • Uploading and rejected-file were not built. ACF hands every upload to the WordPress media modal, so there is no in-field upload to show progress for, and ACF already rejects an oversized or wrong-typed file inside that modal. Building an in-field uploader would mean a second upload path beside ACF's own. The dropzone therefore says Choose a video rather than offering a drag it does not accept.
  • The green "Ready to play" strip was dropped. The style guide reserves green for selection and the primary action; a green dot on every filled field is decoration. The missing-poster line stayed, and is grey — amber is not in the palette.
  • The poster fallback is --canvas with a glyph, not the near-black frame above, so colour never stands in for a photo.
  • The size cap is not stated. ACF puts data-mime_types in the DOM but never max_size, and only the Portraits block sets one. The small print lists accepted formats only.
  • The image field moved to the same row, so the thumbnail above genuinely matches the two video fields below it.
