One field, one presentation. The allowed list is a filter over the same library, so a restricted instance is the same control holding fewer options — an editor who learns it on one block already knows it on every other. Nothing is preselected, which is what makes the asterisk mean something: today the field ships already satisfied, so an editor who never touched it still saves a value they didn't pick. Search and group headers drop out below ten icons because there is nothing to search or group, not because it is a different control. Selection is a filled swatch; green stays on focus, where it means the same thing everywhere else in the editor.
